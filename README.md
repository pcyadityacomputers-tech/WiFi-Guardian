📶 WiFi Guardian

WiFi Guardian is a mobile-friendly Wi-Fi security dashboard designed for networks that you own or are authorized to manage.

Features

- 📡 Wi-Fi network information dashboard
- 🔒 Security-type display
- 📶 Signal-strength display
- 👥 Connected-device monitoring when supported by an authorized router/API
- 🔑 Wi-Fi password-strength checker
- 🛡️ Network security tips
- 📱 Mobile-friendly interface

Technologies

- HTML
- CSS
- JavaScript
- GitHub Pages

Important

WiFi Guardian does not crack Wi-Fi passwords or access networks without permission.

Connected-device information requires authorized access to the relevant router or network API.
